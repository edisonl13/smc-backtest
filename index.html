📖 SMC V10 规则手册
🎯 工具定位
这是一套 SMC/ICT 实盘模拟与复盘工具。它不是为了自动回测，而是为了帮助交易员在真实行情中逐笔执行严格的交易规则，记录每一笔决策的门闸通过情况、情绪、盈亏，并自动统计胜率、期望值、最大连亏等关键指标。通过反复训练，形成肌肉记忆，避免情绪化交易。
🧠 核心逻辑（多周期联动）
日线 → 4H → POI → DOL → KZ 扫荡 → 执行层确认 → 入场
[日线偏见] → [4H结构一致] → [POI区域/质量] → [DOL方向] → [KZ内扫荡] → [CHoCH+FVG] → [RR≥2] → 入场
每个环节的作用：
  • 日线偏见 确定大方向，过滤震荡市。只有多或空，不做震荡。
  • 4H结构 确认中期趋势与日线一致（BOS/CHoCH），避免逆势交易。
  • POI（兴趣区） 找到机构可能进场的区域（折扣区做多，溢价区做空）。质量越高（Q3）胜率越高。
  • DOL（目标点） 明确第一目标（4H未回补FVG或BSL/SSL），保证盈亏比。
  • KZ扫荡 机构制造流动性猎杀散户止损。扫荡后才会出现真正的方向。
  • CHoCH + FVG 确认扫荡后的反转有效，且存在价格失衡，提供精确入场点。
  • RR ≥ 2 强制风险回报比，确保长期正期望值。
  • 情绪/叙事/教训 记录心理状态，暴露弱点，持续改进。
⚡ 关键修正：KZ扫荡的传递性
传统理解要求每个KZ都必须有自己的扫荡才能入场。但实际中，前一个KZ已经完成了扫荡，当前KZ无需重复扫荡，只要出现同向的CHoCH+FVG即可入场。
🔹 示例：伦敦KZ扫了亚洲盘低点（诱空做多） → 价格反转向上，留下FVG。
🔹 纽约KZ开盘后，价格回踩该FVG，并出现15M CHoCH + 5M FVG（做多信号） → 直接做多，不需要等纽约再扫伦敦高点。
✅ 规则更新：在 Phase 2 的 Sweep 选项中，新增 “前序KZ已扫荡（顺势）”。选择此项后，系统不再要求当前KZ必须有扫荡，只要前一个KZ发生过同向扫荡，且当前KZ满足CHoCH+FVG+RR≥2，门闸即通过。
📋 门闸逐项解读
Phase 1（结构门闸） 全部通过才能进入Phase 2：
  • Daily Bias 多/空，震荡则放弃。
  • 4H Structure 必须与Daily方向一致（BOS/CHoCH）。
  • 4H POI Type 必须明确（FVG/OB/重叠），不能无POI。
  • POI Quality 1-3星，3星最佳。
  • POI Zone 多→折扣区，空→溢价区。
  • DOL Target 多→上方目标，空→下方目标，且与偏见一致。
  • Path Obstruction 无阻挡或已调整TP1。
  • Expected Judas 多→扫SSL，空→扫BSL（预期）。
Phase 2（执行门闸） 全部通过才能开仓：
  • Direction 与Phase 1的Bias一致。
  • Sweep 当前KZ扫荡 或 前序KZ已同向扫荡。
  • 15M CHoCH + Displacement 结构转变确认。
  • 5M FVG Valid 有效失衡区域。
  • CE (50% FVG) 限价单挂FVG中位。
  • SL beyond Judas extreme 止损设在扫荡点外侧。
  • Narrative 能清晰说出入场逻辑。
  • RR ≥ 2 盈亏比达标。
💡 常见误区与解答
Q: 一定要在KZ内入场吗？
A: 是的，因为机构订单流集中在KZ时段。但入场不一定需要当前KZ扫荡，可以利用前序KZ的扫荡结果。
Q: 如果当前KZ没有扫荡，但出现了CHoCH+FVG，可以做吗？
A: 可以，前提是前一个KZ已经完成了同向扫荡。规则手册已明确支持这种“传递性”。
Q: 为什么必须等CHoCH+FVG？直接扫完入场不行吗？
A: 扫荡后立即入场容易被反向扫损。等待CHoCH+FVG确认反转，胜率更高。
Q: 工具会帮我自动平仓吗？
A: 不会。这是一套手动记录工具，你需要根据实际价格行为在Phase 3中填写TP1/TP2是否命中、最终结果和实际RR。
🧠 交易纪律比交易技术更重要。每次开仓前，确保所有门闸亮起绿灯。连续亏损3笔，暂停复盘。
📊 100笔回测后，若期望值 > 0.3R 且平静率 > 70%，你的系统已具备正向期望。
